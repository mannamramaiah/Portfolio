# Mannam Ramaiah — Full Stack Developer Portfolio

A modern, responsive personal portfolio website for **Mannam Ramaiah**, a final-year B.Tech Computer Science & Engineering student and aspiring Full Stack Web Developer.

The portfolio showcases my skills, education, projects, certifications, and contact information through a dark, interactive UI with animations and responsive design.

## ✨ Features

* 🎨 Modern dark-themed UI with amber/cyan accent colors
* 📱 Fully responsive design for desktop, tablet, and mobile
* 🖱️ Custom animated cursor
* ✨ Smooth scroll and reveal animations
* 🎬 GSAP-powered hero and section animations
* 🌌 Animated background effects and grid overlay
* 👤 Interactive profile image with mouse movement effect
* 📄 Resume preview in a modal PDF viewer
* 📊 Skills section with animated proficiency bars
* 💼 Featured and completed projects showcase
* 🏆 Certifications and awards section
* 📬 Contact section with email, GitHub, and LinkedIn
* 👁️ Visitor counter
* 📱 Mobile navigation hamburger menu
* 🔗 Project live-demo and GitHub links

## ⚙️ Running Locally

Clone the repository:

```bash
git clone https://github.com/mannamramaiah/<repository-name>.git
```

Move into the project directory:

```bash
cd <repository-name>
```

Because this is a static website, you can open `index.html` directly in a browser.

For a better development experience, use a local server such as VS Code Live Server.
